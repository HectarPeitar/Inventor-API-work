# examples

## Purpose

This directory contains reusable example implementations for Autodesk Inventor automation.

Examples are intended to demonstrate patterns and provide starting points for new work.

---

## What belongs here?

Examples of:

- iLogic rules;
- C# code;
- VB.NET code;
- Inventor API usage;
- Add-in patterns;
- UI examples;
- Assembly operations;
- Parameter operations;
- document operations.

Examples should focus on demonstrating a technique rather than representing a complete production system.

---

## What does NOT belong here?

Do not use this directory for:

- authoritative API documentation;
- behavioral rules;
- untested experimental code presented as working;
- project-specific production code;
- external source archives.

Technical knowledge belongs in:

    knowledge/

AI behavior rules belong in:

    .clinerules/

Verified production-oriented implementations belong in:

    tested/

External source material belongs in:

    reference/

---

## Example Quality

Each useful example should make its context clear.

Where relevant, document:

- Inventor version;
- programming language;
- iLogic or Add-in;
- document type;
- purpose;
- important assumptions;
- limitations.

---

## Tested vs Example

An example does not automatically mean that the code has been verified.

If an example has been successfully tested and is considered reliable, a corresponding implementation may also be stored in:

    tested/

---

## Design Principle

`examples/` answers:

> "How might this be implemented?"

It is primarily a learning and implementation-pattern resource.
