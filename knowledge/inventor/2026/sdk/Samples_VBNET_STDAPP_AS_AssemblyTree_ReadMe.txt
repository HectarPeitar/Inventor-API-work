
  AssemblyTree
  ============
	
  DESCRIPTION
	
  Shows the occurrences in an assembly file for the selected Level of details representation.
  Also displays the referenced documents and referenced files.

  This is a VB.NET application that demonstrates accessing the assembly tree of an Inventor
  assembly document.  It traverses the entire assembly tree and prints out 
  the display name and icon for each subassembly and part encountered. 
 
  Language/Compiler: VB.NET.
  Server: Inventor.

  How to Create This Sample: Build AssemblyTree Project.

  Executable: AssemblyTree.exe

  How to Run this sample: Run AssemblyTree.exe and you will see a "Assembly Tree" Dialog. 
  You can enter the assembly file name to open in the edit box and press refresh button or 
  press the "Browse" button.  This will display a "File Open" dialog which can be used to 
  specify an assembly file. The "Refresh" button refreshes the display of the assembly tree.
  You can select the level of detail representation from the combobox. You can control which 
  of the referenced documents and files should be displayed using the "refernces display options".
