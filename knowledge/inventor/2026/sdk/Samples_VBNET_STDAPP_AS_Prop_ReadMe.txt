
  Properties Sample
  =================
  
  DESCRIPTION
  This Sample demonstrates accessing the file properties of an Autodesk Inventor file using Apprentice Server.

  Language/Compiler: VB.Net
  Server: Apprentice Server.

  How to Create This Sample: Make Properties.exe.

  Executable: Properties.exe.

  How to Run this sample: Run propeties.exe. When run, a form is displayed. The first step is to use the browse
  button to select an Inventor file. The program then iterates through all of the property sets, properties, 
  and their values in the selected file. The results are displayed in a list box on the form. 
  You can double click on any of the properties that contain string values and a dialog will display to 
  allow you to edit the value of the property.
