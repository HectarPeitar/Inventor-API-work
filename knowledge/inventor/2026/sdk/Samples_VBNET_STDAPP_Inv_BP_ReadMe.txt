VBBrowserPanes Sample
=====================

DESCRIPTION:

This sample demonstrates how to insert an ActiveX control in the Browser bar in Autodesk Inventor.


SERVER: Inventor


LANGUAGE/COMPILER: VB.Net


REQUIREMENTS:

This sample requires the ActiveX control SIMPLEMFCCONTROL.ocx.  See instructions below for more details.


INSTRUCTIONS:

To run this sample, do the following:

1. Register the control SIMPLEMFCCONTROL.ocx by entering the following in the Console window:
	
	cd Samples\VB\Standalone Applications\Inventor\BrowserPane\SimleMFCControl\Optimize  (where SDK is the current directory)
	Regsvr32 SIMPLEMFCCONTROL.ocx

2. Start Autodesk Inventor.

3. Start the sample's executable: VBBrowserPanes.exe.

4. In the dialog that appears, click on Connect to connect to an existing session of Inventor.  Note that Inventor must be running in order to run this sample.

5. Once the sample connects to Inventor, the button "Add BrowserPane" is enabled. Click the button "Add BrowserPane" to add a browser pane to the Inventor browser. This opens a new part document and adds a browser pane that contains the ActiveX control (registered in step 1).

6. The List box in this sample's dialog shows different events fired by the ActiveX control and the  BrowserPane object.

7. Once the browser pane is added to Inventor, you can send text to it using the AddText button. You can clear the text using the Clear Contents button.

8. Click Exit to exit the form.
