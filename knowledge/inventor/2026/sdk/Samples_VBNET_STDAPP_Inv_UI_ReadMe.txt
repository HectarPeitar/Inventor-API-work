  User Interaction Sample
  =======================
  
  DESCRIPTION
  This sample demonstrates the functionality exposed through the 
  InteractionEvents object.  The sample serves to exercise the
  various components of the InteractionEvents object and also
  serves as a tool to better understand how these events work.

  To use this sample as-is, first run Autodesk Inventor and have a 
  document open. Then run UserInteraction.exe. This will display a 
  dialog that allows you to interactively control the various options
  of the InteractionEvents object and the associated Select, Mouse, 
  Keyboard and Triad events.  The "Start Interaction" button at the 
  top of the form starts the interaction events running, so you won't 
  see any feedback until you click this.



  Language/Compiler: VB.Net.
  Server: Autodesk Inventor
  
  How to create this sample: Build UserInteraction project to create UserInteraction.exe
  Executable : UserInteraction.exe
