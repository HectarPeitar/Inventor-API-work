
  SimpleApprenticeExe sample
  ==========================
  Shows how to access Inventors Apprentice Server.


  This builds a simple console application that demonstrates how a client may access
  (Inventor's) Apprentice Server from an independent process. The API found in Apprentice 
  is a subset of that found in Inventor.

  This trivial application starts up the Server inside its own process space and:
  1. Opens an Inventor file.
  2. Prints its Display name, Created version, Saved version
  3. Closes the file.

  Language/Compiler: VC++
	Server: Apprentice Server.

  How to Create This Sample: Build SimpleApprenticeExe Project.

  Executable: SimpleApprenticeExe.exe

  How to Run this sample: Run SimpleApprenticeExe. 
	This trivial application starts up the Server inside its own process space and:
  1. Opens an Inventor file.
