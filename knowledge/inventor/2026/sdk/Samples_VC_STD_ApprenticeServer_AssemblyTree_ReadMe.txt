AssemblyTree
  ============
	
  DESCRIPTION
	
  Shows the occurrences in an assembly file after querying for them using the API.
  The sample shows traversing the assembly tree.

  This is a VC++ application that demonstrates accessing the assembly tree of an Inventor
  Assembly using Apprentice Server.  It traverses the entire assembly tree and prints out 
  the display name and icon for each subassembly and part encountered .
 
  Language/Compiler: VC++
  Server: Apprentice Server.

  How to Create This Sample: Build AssemblyTree Project.

  Executable: Assembly Tree.exe

  How to Run this sample: Run AssemblyTree.exe and you will see a "Assembly Tree" Dialog. 
  You can enter the assembly file name to open in the edit box or press the "Browse" button.
  This will display a "File Open" dialog which can be used to specify an assembly file. 
  The "Refresh Tree" button displays the entire assembly tree.
