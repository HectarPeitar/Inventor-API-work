  CurvatureApp
  ============

  DESCRIPTION

  Demonstrates reading the Brep data from the BRep segment of an Inventor
  part or assembly file using either the Apprentice server or by connecting
  to a running session of Inventor.

  This is a basic MFC-based MDI application created using the MFC AppWizard.
  CurvatureApp documents can be created, opened, and saved using the standard
  "File" menu options. Once a document is created or opened, an Inventor part
  or assembly file can be "referenced".

  When a part or assembly is referenced, the Inventor file is opened, and
  the surface body geometry from the main component definition is read. In
  addition, the surface body geometry from any sub-occurrences is also read
  (for assembly files). Once the file is read, the information is kept in
  the CurvatureApp document and is displayed in the window using OpenGL.

  With the file referenced, various measurement commands can be used to
  operate on the Inventor geometry and a display showing the curvature of
  any of the displayed faces can be turned on.

  This sample is broken up into three areas. The files located in the top
  level "CurvatureApp" directory are the files generated by the MFC AppWizard
  with all of the code implementation filled in. The "AppRelated" folder
  contains files dealing with managing the referenced file, the dialogs
  used for the various tools commands, the OpenGL display engine. Lastly,
  the "InventorRelated" folder contains the files with the code that
  interfaces directly with the Inventor or Apprentice servers.

  This sample also demonstrates a method of maintaining associativity to the
  part or assembly.  To see this demonstrated, open a part or assembly and
  run one of the measurement commands.  Open the same part or assembly in
  Inventor and make a modification.  Now go back to the CurvatureApp and
  run the "Update Inventor File".  You should now see the latest version of
  the file and if you run the measurement command again it will automatically
  show the results for the entity previously selected.  Using something
  called "reference keys", CurvatureApp is able to reconnect to objects
  between sessions and even after changes have occurred.  This allows external
  applications to remain associate to Inventor objects. 

  Language/Compiler: VC++
  Server: Apprentice Server, Inventor Server

  How to Create This Sample: Build CurvatureApp Project.

  Executable: CurvatureApp.exe

  How to Run this sample: Run the CurvatureApp.exe, create a new document,
  and then select "Reference Inventor File" from the "File" menu.

  If there is an Inventor session running, you will be asked if you would like
  to use the running session to read the file. If you select "yes", the running
  session will be used. If you select "no", or if there is no Inventor session
  running, the Apprentice server will be used.

  Once the geometry from the selected file is displayed, you can use the
  "Tools" menu to perform tasks such as displaying the curvature on a selected
  face, measuring the length of a selected edge, or measuring the area of a
  selected face.

  Note about graphics cards
  =========================
  The OpenGL implementation in the CurvatureApp is not as robust and general
  purpose as the one in Inventor proper. Some graphics cards that aren't
  supported by Inventor will still work with Inventor using software graphics
  while, in the CurvatureApp, you will get a failed display. Most notably,
  the Matrox Millenium cards have caused problems in the CurvatureApp.

  If you experience display problems, there is one change you can make
  that may help. In the file "AppRelated\CurvatureAppDisplay.cpp" at or
  around line #21, you will find the following commented out definition.

    #define USE_FRONT_BUFFER_ONLY

  Uncommenting that line will force the display code to run in single
  buffered mode which has been known to fix the display on some graphics
  cards.
