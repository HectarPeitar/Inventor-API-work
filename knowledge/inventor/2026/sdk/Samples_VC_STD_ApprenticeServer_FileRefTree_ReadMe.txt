  FileRefTree sample
  ================

  DESCRIPTION

    This builds a simple MFC application that demonstrates how a client may use
    Apprentice to access to document references information.
  
  Language/Compiler : Visual C++
  Server: Apprentice server.

  How to create this sample?
	Build FileRefTree.exe

  Executable : FileRefTree.exe

  How to run this sample?
	Run FileRefTree.exe and a file open dialog box will pop-up.
    Select a file and the sample will dump out all the relevant document reference information.
